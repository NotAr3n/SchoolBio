# BioStudy App

A modern, lightweight, responsive study web application built directly from textbook curriculum content (Ecology, Energy Flow, Matter Cycles, Population Dynamics, and Biodiversity). 

Features complete study notes, interactive multiple-choice quizzes with explanations, flashcards with flip/shuffle/mastery tracking, and persistent local storage.

---

## 🚀 How to Deploy to GitHub & Vercel in 2 Minutes

### Step 1: Upload to GitHub
1. Create a new repository on [GitHub](https://github.com/new) (name it `biostudy`, keep it public).
2. Upload all 5 project files (`index.html`, `style.css`, `content.js`, `app.js`, `README.md`) directly into the repository.

### Step 2: Deploy to Vercel
1. Go to [Vercel](https://vercel.com/) and log in with your GitHub account.
2. Click **Add New...** -> **Project**.
3. Import your `biostudy` repository.
4. Leave all build settings as default (no build command or output directory is needed since it's pure static HTML/CSS/JS).
5. Click **Deploy**. Vercel will instantly generate a live URL for you and your friends to study from!
